# LendingClub Loan Data Analysis using Python

## Objective

Analyze LendingClub loan data to understand borrower behavior, loan characteristics, and factors influencing loan repayment.

## Dataset

The dataset contains historical loan data from LendingClub including borrower details, loan amount, interest rate, and repayment status.

## Tools & Libraries

Python
Pandas
NumPy
Matplotlib
Seaborn

## Steps Performed

* Data cleaning and preprocessing
* Handling missing values
* Exploratory Data Analysis (EDA)
* Data visualization
* Identifying patterns in loan defaults

## Key Insights

* Certain loan grades have higher default rates.
* Borrowers with higher income show lower default probability.
* Loan purpose influences repayment behavior.

## Skills Demonstrated

* Data Cleaning
* Exploratory Data Analysis
* Data Visualization
* Financial Data Analysis
